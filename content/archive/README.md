# Unpublished archive

Previous days' articles and daily data files live here so they are **not published**. The live site only loads files from `content/articles/`, `content/scores/`, `content/streaming/` and `content/x/`.

Each morning, before publishing the new edition:

1. Move yesterday's articles from `content/articles/` into `content/archive/articles/`, except any story that has a genuine update today. For those, set `date` (and `updated`) to today and leave the file in `content/articles/`.
2. Move yesterday's `content/streaming/` and `content/x/` files here, and move older `content/scores/` files here, leaving only the current edition (scores are named for last night's game date).

Do not link to archived stories from the live site.
